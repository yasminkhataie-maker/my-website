# سایت Veloxitas Agency

این پوشه یه سایت کاملاً جداست و به سایت دیگه‌ی توی ریشه‌ی این ریپو (سایت مشاوره‌ی «Let's Put EYE on You») هیچ کاری نداره و دست بهش نخورده.

## فایل‌ها
- `index.html` — کل صفحه
- `styles.css` — رنگ‌ها، فونت‌ها، چیدمان (متغیرهای رنگی بالای فایل هستن اگه خواستی رنگ کلی سایت رو عوض کنی)
- `script.js` — منوی موبایل، آکاردئون، انیمیشن‌ها، و حالت ویرایش
- `assets/placeholder.svg` — عکس جایگزین موقت (تا عکس واقعی بذاری)

## چطور متن و عکس‌ها رو خودم عوض کنم؟ (بدون کدنویسی)

۱. سایت رو باز کن و در آخر آدرس، این رو اضافه کن:
```
?edit=1
```
مثلاً اگه سایت اینجاست: `.../veloxitas-agency/index.html` بازش کن با:
`.../veloxitas-agency/index.html?edit=1`

۲. یه نوار بنفش بالای صفحه ظاهر می‌شه که یعنی «حالت ویرایش فعاله».

۳. **برای تغییر متن:** روی هر تیتر، پاراگراف یا متن دکمه کلیک کن، مستقیم تایپ کن (مثل ورد). خودش ذخیره می‌شه.

۴. **برای تغییر عکس:** روی هر عکس (که دور بنفش‌چین داره) کلیک کن، عکس خودت رو از گوشی/کامپیوتر انتخاب کن — جای عکس placeholder می‌شینه.

۵. پایین صفحه یه نوار کوچیک هست با سه دکمه:
   - **دانلود نسخه نهایی** → یه فایل `index.html` با همه‌ی تغییراتت دانلود می‌شه. همین فایل رو جای فایل قبلی (توی این پوشه) بذار و آپلودش کن — تمام.
   - **بازگردانی** → همه‌ی تغییرات رو پاک می‌کنه و به حالت اول برمی‌گردونه.
   - **بستن ویرایش** → از حالت ویرایش خارج می‌شی و صفحه رو عادی می‌بینی (تغییراتت باقی می‌مونن، فقط دیگه قابل کلیک-ویرایش نیستن).

> نکته: تا وقتی فایل نهایی رو دانلود و جایگزین نکردی، تغییرات فقط توی همون مرورگر خودت ذخیره می‌مونن (روی گوشی/کامپیوتر دیگه یا برای بازدیدکننده‌ها دیده نمی‌شن). برای اینکه همه ببینن، حتماً مرحله‌ی «دانلود نسخه نهایی» رو انجام بده.

## رنگ‌بندی و فونت
- رنگ اصلی: سرمه‌ای تیره `#12124a` + بنفش `#6d28d9`
- فونت تیترها: Space Grotesk / فونت متن: Inter (هر دو از Google Fonts، رایگان)
- برای عوض کردن رنگ‌ها، بالای فایل `styles.css` بخش `:root` رو ببین.
